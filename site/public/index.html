What it does

Six things, one click away.

Power modes

Low Power, Automatic and High Power as three buttons. No trip to System Settings. It can also drop to Low Power by itself below 20% and switch back when you plug in.

Charge limit

Pick any percentage from 40 to 100, one percent at a time. Charging stops there and starts again 3% lower. Need a full battery for a trip? Charge to full once, then it goes back.

Live energy flow

A chart of watts in and watts out, refreshed every second from the Mac's own power sensors: charger and battery on the left; CPU, GPU, memory, display and charging on the right.

Look one level deeper

Click CPU or Memory to see which apps the power is going to. Click Display & other to see the chip rails that have their own sensor.

Activity Monitor, shorter

The apps using the most energy, memory and CPU, with per-core load and the memory breakdown. Hover a row to quit the app; hold Option to force quit.

Battery facts

Health, cycle count, temperature, time remaining, and how fast it is charging or draining right now.

Honest numbers

It says which figures are measured and which are worked out.

Measured
Charger input, battery flow, total system load, CPU, GPU and memory power. Read directly from sensors, once a second, with no smoothing.
Worked out
“Display & other” is the system total minus the measured chips. “Conversion loss” is what came in minus what was delivered.
Estimated
Per-app watts. The Mac doesn't measure power per app, so CPU power is split by each app's share of CPU time, and the panel labels it as an estimate.
Not shown
Per-app GPU power and a screen backlight figure. macOS doesn't report them, so Juice doesn't guess.

Install

Three steps, about a minute.

  1. Download and drag Juice to Applications. Open it from there. The first time, macOS may ask you to confirm: System Settings › Privacy & Security › Open Anyway.
  2. Click the battery in your menu bar, then Install Helper. Changing power modes and stopping charging both need administrator rights, so macOS asks for your password once.
  3. Hide the system battery icon. System Settings › Control Centre › Battery › turn off Show in Menu Bar. Juice shows the same things and more.

Built and tested on an M4 Pro MacBook Pro running macOS 26. Other Apple silicon MacBooks should work, but haven't been tested; High Power Mode only exists on models that support it. The helper can do two things only: set the power mode and set the charge limit. If you use another charge limiter, such as AlDente, quit it first so the two don't fight. To remove Juice, open the panel while holding Option, choose Uninstall Helper, then quit and delete the app.
